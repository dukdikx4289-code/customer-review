# คู่มือแอดมิน (สำนักงานกลาง)

เข้าที่ `https://<โดเมนของคุณ>/admin/` ด้วยชื่อผู้ใช้/รหัสผ่านที่ได้รับ

## งานที่ทำได้

| เมนู | ใช้ทำอะไร |
|---|---|
| ภาพรวม | ดูผลรวมทุกสาขา กรองตามช่วงเวลา/สาขา (หน้าตาเหมือนที่ผู้บริหารเห็น) |
| สาขา | เพิ่ม/แก้ชื่อ/ปิดสาขา และกด "ดูผลและลิงก์" เพื่อดูผล ลิงก์ QR และคำตอบเฉพาะสาขานั้น |
| ลิงก์และ QR | สร้างลิงก์ลูกค้า (ต่อสาขา) และลิงก์ผู้บริหาร ดาวน์โหลด QR |
| คำถาม | เพิ่ม/ลบ/เรียงลำดับ/แก้ข้อความคำถาม แล้ว "เผยแพร่" |
| คำตอบ | ดูคำตอบดิบทั้งหมด |
| บัญชี | เปลี่ยนรหัสผ่าน / ออกจากระบบ |

## ขั้นตอนเริ่มใช้งานจริง

1. **สาขา** → เพิ่มสาขาทั้งหมด (รหัสสาขาใช้ A–Z 0–9 `_` `-`)
2. เข้าหน้าแต่ละสาขา → แท็บ **ลิงก์และ QR** → สร้างลิงก์ลูกค้า ตั้งชื่อให้รู้ว่าติดที่ไหน (เช่น "QR หน้าร้าน", "สติกเกอร์กล่องส่งเดลิเวอรี่")
3. ดาวน์โหลด QR (SVG เหมาะกับงานพิมพ์ขนาดใหญ่, PNG สำหรับใส่ในเอกสาร) → พิมพ์ → **ทดลองสแกนด้วยมือถือจริงก่อนพิมพ์จำนวนมาก**
4. เมนู **ลิงก์และ QR** → สร้างลิงก์ **ผู้บริหาร** (ขอบเขต "ทุกสาขา") → ส่งให้ผู้บริหารโดยตรง (LINE/อีเมลส่วนตัว) ผู้บริหารเปิดดูได้เลยไม่ต้องล็อกอิน

## ลิงก์ลูกค้า vs ลิงก์ผู้บริหาร

- **ลิงก์ลูกค้า**: ใครสแกนก็ตอบได้ ไม่จำกัดจำนวนครั้ง ผูกกับสาขา — ไม่ต้องให้ลูกค้าเลือกสาขา
- **ลิงก์ผู้บริหาร**: เป็นความลับ ใครมีลิงก์ก็ดูข้อมูลได้ (อ่านอย่างเดียว) อย่าโพสต์ในกลุ่มสาธารณะ
  - เห็นว่าถูกเปิดดูกี่ครั้ง/ครั้งล่าสุดเมื่อไร — ถ้าเห็นการเปิดที่ผิดปกติ ให้ **หมุนเวียนลิงก์**
  - ตั้งวันหมดอายุได้ (เช่น ลิงก์สำหรับรายงานไตรมาส)

## หมุนเวียน / ปิด ลิงก์

- **หมุนเวียนลิงก์ (ออกใหม่)**: ลิงก์/QR เดิมใช้ไม่ได้ทันที ลิงก์ใหม่ปรากฏบนหน้าเดิม — ใช้เมื่อลิงก์ผู้บริหารรั่ว หรือ QR ถูกนำไปใช้ผิดที่ (QR ที่พิมพ์ไปแล้วต้องพิมพ์ใหม่)
- **ปิดใช้งาน**: หยุดชั่วคราว เปิดกลับมาได้ด้วยลิงก์เดิม

## แก้คำถาม

- เพิ่ม/ลบ/เรียงลำดับ/แก้ข้อความ แล้วกด **เผยแพร่** → ระบบสร้าง "เวอร์ชันใหม่" ลูกค้าที่เปิดฟอร์มหลังจากนั้นเห็นชุดใหม่ทันที
- **คำตอบเก่าไม่ถูกแก้** และ Dashboard ยังรวมข้อมูลได้ต่อเนื่อง เพราะคำถามเดิมมีรหัสภายในคงที่ (แสดงเป็นตัวเล็กๆ ข้างชื่อ) — แก้ถ้อยคำได้โดยเทรนด์ไม่ขาด
- ถ้าเปลี่ยน **ความหมาย** ของคำถาม ให้ลบข้อเก่าแล้วเพิ่มข้อใหม่ (จะได้รหัสใหม่ เทรนด์เริ่มนับใหม่)
- ชนิดคำถาม: ให้คะแนนดาว, เลือกข้อเดียว, เลือกหลายข้อ, ข้อความสั้น, ข้อความยาว
- Dashboard แสดงกราฟ/แถบคะแนนเฉพาะคำถามแบบ "ให้คะแนนดาว" และแสดงข้อความของคำถามแบบข้อความเป็น "ข้อเสนอแนะ"

## อ่าน Dashboard

- **จัดการ์ดเองได้**: ลากการ์ดเพื่อสลับตำแหน่ง (มือถือ/iPad: กดการ์ดค้างไว้แล้วลาก, คีย์บอร์ด: Alt + ลูกศร) ระบบจำลำดับไว้ในเบราว์เซอร์ของแต่ละคน กด "รีเซ็ตการจัดวาง" เพื่อกลับค่าเริ่มต้น
- ปุ่ม ⤢ มุมการ์ด: เปิดดูแบบเต็มหน้าต่าง (ตารางสาขาเรียงตามคอลัมน์ได้, ข้อเสนอแนะกรองตามจำนวนดาวได้) กด Esc หรือคลิกพื้นหลังเพื่อปิด
- ลูกศร ↑↓ ในการ์ด = เทียบกับ "ช่วงก่อนหน้า" ที่ยาวเท่ากัน (เช่น 30 วันนี้เทียบ 30 วันก่อนหน้า) ไม่แสดงเมื่อเลือก "ทั้งหมด"
- แผนที่ช่องสี่เหลี่ยมในการ์ด "จำนวนรีวิว" = รีวิวรายชั่วโมงของ 7 วันล่าสุด ยิ่งเข้มยิ่งมาก

- **ความพึงพอใจ %** = สัดส่วนคนที่ให้ 4–5 ดาวในหัวข้อ "ความพึงพอใจในการสั่งอาหารครั้งนี้"
- **จุดที่ต้องแก้ไข** = หัวข้อ×สาขาที่เฉลี่ยต่ำกว่า 3.5 และมีอย่างน้อย 3 รีวิว
- **เปรียบเทียบสาขา**: ช่องยิ่งเข้มคะแนนยิ่งสูง, ⚠ = ต่ำกว่าเกณฑ์
- ข้อมูลอัปเดตทุก ~1 นาที (มีแคชสั้นๆ)

## Google Sheets

ทุกคำตอบถูกส่งไปที่ชีทอัตโนมัติ (แท็บ `responses`) ภายใน ~1 นาที — **อย่าแก้หัวตาราง (แถวแรก) และอย่าลบ/สลับคอลัมน์** เพราะระบบเขียนต่อท้ายตามหัวตาราง ถ้าเพิ่มคำถามใหม่ ระบบจะเพิ่มคอลัมน์ต่อท้ายให้เอง ทำ pivot/กราฟในแท็บอื่นของชีทได้อย่างอิสระ

## ความเป็นส่วนตัว

ระบบ **ไม่เก็บ IP/ชื่อ/เบอร์ลูกค้า** โดยค่าเริ่มต้น (เก็บแค่คำตอบ, สาขา, เวลา, ชนิดเบราว์เซอร์) — ถ้าเพิ่มคำถามที่ขอเบอร์โทร/อีเมล ควรใส่ข้อความแจ้งวัตถุประสงค์และขอความยินยอมในข้อความคำถาม (PDPA)
